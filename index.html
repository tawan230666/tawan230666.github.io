01 Selected work

Full-stack · Team project

BizFlow: QR table ordering

Diners scan a QR code at their table, order from their phone and pay with a PromptPay QR. The kitchen and cashier see every order change instantly.

  • Prices are always recomputed on the server, so a tampered request can't change the bill
  • JWT roles (admin, kitchen, cashier) guard every endpoint
  • Orders, payments and table state change together in one database transaction
  • Socket.IO rooms push live order status to the kitchen and to each diner

TypeScript · React · Express · Prisma · MySQL · Socket.IO · Docker

Machine learning · Computer vision

Bean snack detection with YOLO

A custom detector that finds and classifies the 5 ingredients of a Thai mixed-bean snack in photos, video and a live camera feed. I built every stage myself: data collection, labelling, dataset tooling, training, evaluation and inference.

  • 0.914 mAP@50 and 0.93 recall on held-out images
  • About 120 ms per image on a CPU, with no GPU

02 One app, five architectures

In my Software Architecture course I rebuilt the same task board five times. Each repository documents what changed and why.

  1. LayeredControllers, services and repositories in one process
  2. N-tier + DockerNginx, API and PostgreSQL as separate containers
  3. Scaled + cached3 API instances, round-robin load balancing, Redis cache-aside with graceful fallback
  4. Event-drivenRabbitMQ fanout to independent notification and audit consumers
  5. Secured microservicesA gateway, JWT, a database per service, deployed to Railway
